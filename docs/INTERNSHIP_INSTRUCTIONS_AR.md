## 🛠️ دليل التنفيذ خطوة بخطوة

### 🔹 المستوى الأول (Level 1): الأساسيات
**المهمة 1: تنظيف البيانات (`01_data_cleaning.ipynb`)**
1. تحميل `iris.csv` عبر `pd.read_csv()`
2. اكتشاف القيم المفقودة: `df.isnull().sum()`
3. التعامل مع القيم المفقودة: `df.fillna(method='ffill')` أو `SimpleImputer`
4. كشف الشذوذ: استخدام `IQR` أو `Z-score`، ثم تصفية أو استبدال القيم القصوى
5. الترميز: `LabelEncoder` أو `OneHotEncoder` للمتغيرات الفئوية
6. التطبيع: `StandardScaler` للمتغيرات العددية
✅ **نصيحة ذهبية:** استخدم `sklearn.pipeline.Pipeline` لربط الخطوات ومنع تسرب البيانات (Data Leakage).

**المهمة 2: التحليل الاستكشافي EDA (`02_eda.ipynb`)**
1. الإحصائيات الوصفية: `df.describe()`, `df.info()`
2. التوزيعات: `sns.histplot()`, `sns.boxplot()`
3. العلاقات: `sns.heatmap(df.corr(), annot=True, cmap='coolwarm')`
4. التصور المتقدم: `sns.pairplot()`, `sns.scatterplot()`
✅ **نصيحة ذهبية:** اربط كل رسم بياني بسؤال عمل (مثلاً: "هل طول البتلة يرتبط بنوع الزهرة؟").

---

### 🔹 المستوى الثاني (Level 2): النمذجة
**المهمة 1: الانحدار التنبؤي (`01_regression_modeling.ipynb`)**
- البيانات: `house_prices.csv`
1. تقسيم البيانات: `train_test_split(test_size=0.2, random_state=42)`
2. النماذج: `LinearRegression`, `DecisionTreeRegressor`, `RandomForestRegressor`
3. التقييم: `mean_squared_error`, `r2_score`
4. المقارنة: جدول يجمع `MSE` و `R²` لكل نموذج
✅ **نصيحة ذهبية:** استخدم `cross_val_score` للتحقق من ثبات النموذج على بيانات مختلفة.

**المهمة 2: التجميع غير الخاضع للإشراف (`02_clustering.ipynb`)**
- البيانات: `customer_churn.csv` (⚠️ احذف عمود `Churn` قبل التطبيق، استخدم الميزات الديموغرافية والاستخدام فقط)
1. القياس: `StandardScaler` (إجباري لخوارزميات المسافة)
2. تحديد `k` الأمثل: `elbow_method` + `silhouette_score`
3. التنفيذ: `KMeans(n_clusters=optimal_k)`
4. التمثيل: `PCA(n_components=2)` ثم `sns.scatterplot(hue=clusters)`
✅ **نصيحة ذهبية:** فسّر العناقيد بمتوسطات كل ميزة (مثلاً: مجموعة "ذوي الاستخدام العالي والفواتير المرتفعة").

---

### 🔹 المستوى الثالث (Level 3): التحليل المتقدم
**المهمة 1: السلاسل الزمنية (`01_time_series.ipynb`)**
- البيانات: `airline_passengers.csv`
1. فهرسة التاريخ: `df['Month'] = pd.to_datetime(...)`, `df.set_index(...)`
2. التفكيك: `seasonal_decompose(data, model='additive')`
3. التنبؤ: `SARIMAX` أو `ARIMA` عبر `statsmodels`
4. التقييم: `RMSE` ومقارنة `actual vs forecast`
✅ **نصيحة ذهبية:** لا تخلط البيانات زمنيًا. استخدم `df[:-n]` للتدريب و `df[-n:]` للاختبار.

**المهمة 2: تصنيف النصوص NLP (`02_nlp_classification.ipynb`)**
- البيانات: `sentiment_reviews.csv`
1. التنظيف: إزالة الرموز، التحويل لحروف صغيرة، `nltk.word_tokenize`، إزالة `stopwords`
2. التمثيل: `TfidfVectorizer`
3. النموذج: `LogisticRegression` أو `MultinomialNB`
4. التقييم: `precision_recall_fscore_support`, مصفوفة الارتباك
✅ **نصيحة ذهبية:** استخدم `Pipeline([('tfidf', TfidfVectorizer()), ('clf', LogisticRegression())])` لضمان سلاسة النشر.
